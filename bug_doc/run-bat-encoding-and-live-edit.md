# run.bat の躓き2件(Step 5、2026-07-17)

## 1. UTF-8日本語コメントの誤実行

- **事象**: `run.bat` 実行時、冒頭で `'.yamlが相対パスのため...' is not recognized as an internal or external command` が出力された
- **原因**: batファイルをUTF-8で保存したが、cmdは`.bat`をcp932(Shift-JIS)として読む。`rem`行の日本語がバイト境界のずれで別トークンに化け、一部がコマンドとして実行された
- **影響**: コメント行のみ。`cd`と`uv run`は正常に動作しパイプラインは完走
- **対処**: batファイル内のコメントはASCIIのみとするルールに変更(run.bat内にNOTEとして明記)

## 2. 実行中のbatファイル書き換えによる二重実行

- **事象**: 上記1の修正のためパイプライン実行中(LLM分析で約12分)にrun.batを書き換えたところ、1回目の完走直後にパイプラインが**もう一度実行された**
- **原因**: cmdはバッチファイルを一括ロードせず、**バイトオフセットで逐次読み**する。実行中にファイルを書き換えると、次の行を新しいファイル内容の同オフセットから読むため、意図しない行が実行される
- **影響**: 実害なし。2回目は新着0件・pending 0件・通知0件で正常終了。**statusベースのキュー設計により再実行が冪等である**ことが偶然実証された
- **教訓**: 実行中のbatは書き換えない。長時間走るバッチを直すときは完走を待つ
